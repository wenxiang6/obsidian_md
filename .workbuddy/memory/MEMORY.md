# 项目记忆 — KnowledgeOS (Obsidian 仓库)

## 仓库结构约定

用户维护三个核心文件夹：
- `备忘录/` — 按日期命名的 MD 文档（`YYYY-MM-DD.md`），同日多条目倒序排列
- `Images/` — 图片资源，以中文关键信息命名（如 `会议白板记录.jpg`）
- `skills/` — 技能文档

## memo-manager 技能

- 位置：`skills/memo-manager/SKILL.md`（用户可见）+ `.workbuddy/skills/memo-manager/SKILL.md`（WorkBuddy 调用）
- 触发：用户发送文字或图片时自动触发
- 流程：提取内容 → 判定日期 → 创建/更新备忘录 → 移动图片 → 相对路径引用
- 图片引用格式：`[描述](../Images/文件名.jpg)`（链接，不嵌入）
- **更新规则（2026-08-21 用户要求）**：同一主题的更新必须**覆盖整合**——新信息覆盖旧值、保留仍有效的旧信息、删除旧的独立条目，只保留一份整合后的条目放在文件最顶部；不同主题才新增独立条目

## 用户偏好

- 习惯通过截图而非文字提供信息
- 偏好简洁输出，去掉非核心内容
- 倾向于让 AI 直接执行而非讨论确认
