# 2026-08-20 工作日志

## 创建 memo-manager 技能

- 在 Obsidian 仓库的 `skills/memo-manager/SKILL.md` 创建了备忘录维护技能
- 同时复制到 `.workbuddy/skills/memo-manager/SKILL.md` 供 WorkBuddy 自动发现调用
- 技能功能：用户发送文字/图片 → 提取关键内容 → 按日期归档到 `备忘录/YYYY-MM-DD.md` → 图片移至 `Images/` 并以关键信息命名 → 备忘录通过相对路径引用图片
- 命名规范：备忘录文件用 `YYYY-MM-DD.md`，图片用中文描述性命名
- 排序规则：同一日期多条目倒序（新在上），文件夹整体按日期从新到旧
