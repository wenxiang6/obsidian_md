# 鸿蒙开发工程师面试自我介绍

## 口述版（约2.5分钟，建议背熟后自然表达）

---

面试官好，我叫宫文祥，3年鸿蒙和Android双端开发经验，持有 HarmonyOS 应用开发者高级认证。

我的核心定位是**纯血鸿蒙原生应用开发**，做的是 HarmonyOS NEXT，纯血鸿蒙

最进的项目是**淘宝小程序鸿蒙端 JSBridge 适配**。在这个项目里，我基于鸿蒙 MegaAbility 架构，完成了 150 多个小程序 Native API 与鸿蒙系统能力的对接，搭建了完整的 Bridge 层，覆盖设备信息、网络请求、本地存储、媒体处理、路由导航、授权登录等核心模块。其中文件系统模块从接口定义到真机验证是我独立闭环交付的，包含 20 多个方法。另一个难点是三端协议对齐——鸿蒙、Android、iOS 三端在数字类型转换、Content-Type 兼容、文件编码格式上差异很大，我抽象了统一协议层做适配。同时我还实现了小程序 scope 分级授权闭环，把鸿蒙系统权限映射成小程序权限，从授权引导到失败拦截形成完整闭环。这个项目里我兼任小项目经理，负责任务拆解、进度管控和对外汇报。

第二个项目是**灵锡市民服务应用**，这是一个 Android 存量业务向鸿蒙完整迁移的项目。我独立完成了乘车码、账单、钱包、政策服务等核心模块的全量迁移，同时持续维护 Android 端。技术上用 v2 装饰器驱动深层嵌套对象刷新，EventHub 解耦跨组件通信，PersistentStorage 持久化用户数据。还集成了华为一键登录、微信 SDK、统一扫码、指纹认证等系统能力。性能方面，我在 aboutToDisappear 里统一销毁 WebView 和注销监听，用 Profiler 验证内存平稳，在 onBackground 里暂停定位和二维码刷新降低功耗。

除了鸿蒙，我还有前端技术栈——Vue3、TypeScript、Uni-App，做过 Web 端和小程序端的开发。也了解 Kotlin Multiplatform 跨平台方案，掌握 expect/actual 机制做共享逻辑层。

总的来说，我的优势是**鸿蒙纯血开发 + Android 双端迁移经验 + 工程化交付能力**。对交付质量负责，能独立从 0 到 1 完成鸿蒙应用开发。以上就是我的自我介绍，谢谢。
