# 腾讯 AI前端工程师 面试题（第1组）

## 1. 为什么Vue不需要Fiber设计？

**答案：**
**Vue和React的架构差异：**

1. **响应式系统差异**：
   - **Vue**：基于依赖追踪的响应式系统，精确知道哪些组件需要更新
   - **React**：基于状态的重新渲染，需要Fiber来调度和中断更新

2. **更新粒度**：
   ```javascript
   // Vue - 精确更新
   const vm = new Vue({
     data: { count: 0, name: 'test' },
     template: `<div>{{ count }}</div>`
   });
   // 只有count变化时，才更新相关DOM
   
   // React - 整体重新渲染
   function Component() {
     const [count, setCount] = useState(0);
     const [name, setName] = useState('test');
     // 任何状态变化都会重新执行整个组件函数
     return <div>{count}</div>;
   }
   ```

3. **模板编译优化**：
   ```javascript
   // Vue模板编译时标记静态节点
   // 编译后的render函数
   function render() {
     return _c('div', [
       _c('span', { staticClass: 'static' }, [_v('静态内容')]),
       _c('span', [_v(_s(count))])  // 只有这个是动态的
     ]);
   }
   ```

4. **Fiber解决的问题**：
   - **时间切片**：将渲染工作分成小块，避免阻塞主线程
   - **优先级调度**：高优先级更新可以中断低优先级更新
   - **并发模式**：支持同时处理多个更新

**Vue为什么不需要Fiber：**
1. **精确更新**：Vue的响应式系统已经知道哪些组件需要更新，不需要全量渲染
2. **编译时优化**：Vue在编译时标记静态节点，运行时跳过不必要的对比
3. **异步更新队列**：Vue使用微任务队列批量更新，天然避免了同步阻塞
4. **组件粒度**：Vue的更新粒度是组件级别，而React是整个子树

## 4. HTTP1、2、3各个版本的协议有哪些区别？

**答案：**
**HTTP版本对比：**

| 特性 | HTTP/1.1 | HTTP/2 | HTTP/3 |
|------|----------|--------|--------|
| **传输协议** | TCP | TCP | QUIC (UDP) |
| **多路复用** | ❌ | ✅ | ✅ |
| **头部压缩** | ❌ | ✅ (HPACK) | ✅ (QPACK) |
| **服务器推送** | ❌ | ✅ | ✅ |
| **连接建立** | TCP握手 | TCP+TLS握手 | 0-RTT/1-RTT |
| **队头阻塞** | ✅ | ✅ (TCP层) | ❌ |

**详细区别：**

1. **HTTP/1.1**：
   ```javascript
   // 队头阻塞问题
   // 请求必须按顺序处理
   GET /style.css HTTP/1.1
   Host: example.com
   
   GET /script.js HTTP/1.1
   Host: example.com
   // 必须等待style.css返回后才能处理script.js
   
   // 解决方案：并发连接（通常6-8个）
   // 域名分片
   const urls = [
     'https://cdn1.example.com/resource',
     'https://cdn2.example.com/resource',
   ];
   ```

2. **HTTP/2**：
   ```javascript
   // 二进制分帧层
   // 将请求/响应分割为更小的帧
   
   // 多路复用
   // 一个TCP连接可以处理多个请求/响应
   // 帧可以交错发送
   
   // 头部压缩（HPACK）
   // 使用静态表和动态表压缩头部
   
   // 服务器推送
   // 服务器可以主动推送资源
   Link: </style.css>; rel=preload; as=style
   ```

3. **HTTP/3**：
   ```javascript
   // 基于QUIC协议
   // 解决TCP队头阻塞问题
   
   // 0-RTT连接建立
   // 客户端可以在第一个包中发送数据
   
   // 连接迁移
   // 基于连接ID而非IP:Port
   // 网络切换时连接不断开
   
   // 改进的拥塞控制
   // 更精细的流控制
   ```

**前端影响：**

```javascript
// HTTP/1.1 优化
// 1. 域名分片
const domains = ['cdn1.example.com', 'cdn2.example.com'];

// 2. 资源合并
// 合并CSS/JS文件

// 3. 雪碧图
// 合并小图标

// HTTP/2 优化
// 1. 多路复用，无需域名分片
// 2. 服务器推送
// 3. 头部压缩

// HTTP/3 优势
// 1. 更快的连接建立
// 2. 更好的移动网络支持
// 3. 解决队头阻塞
```

## 7. 为什么选SSE？说一下你们SSE是怎么实现的，怎么断点重连的？

**答案：**
**选择SSE的原因：**

1. **简单易用**：浏览器原生支持，无需额外库
2. **自动重连**：内置断线重连机制
3. **文本优化**：适合AI对话场景
4. **HTTP兼容**：基于HTTP，易于部署和调试

**完整SSE实现：**

```javascript
class EnhancedSSEClient {
  constructor(url, options = {}) {
    this.url = url;
    this.options = {
      reconnectInterval: 3000,
      maxReconnectAttempts: 5,
      heartbeatTimeout: 30000,
      ...options
    };
    
    this.eventSource = null;
    this.reconnectAttempts = 0;
    this.heartbeatTimer = null;
    this.lastEventId = null;
    this.listeners = new Map();
    this.isConnecting = false;
  }
  
  // 连接
  connect() {
    if (this.isConnecting) return;
    this.isConnecting = true;
    
    const url = new URL(this.url);
    if (this.lastEventId) {
      url.searchParams.set('lastEventId', this.lastEventId);
    }
    
    this.eventSource = new EventSource(url.toString());
    
    // 连接成功
    this.eventSource.onopen = () => {
      console.log('SSE连接已建立');
      this.reconnectAttempts = 0;
      this.isConnecting = false;
      this.startHeartbeat();
      this.emit('open');
    };
    
    // 接收消息
    this.eventSource.onmessage = (event) => {
      this.lastEventId = event.lastEventId;
      this.resetHeartbeat();
      
      try {
        const data = JSON.parse(event.data);
        this.emit('message', data);
      } catch (error) {
        this.emit('error', error);
      }
    };
    
    // 连接错误
    this.eventSource.onerror = (error) => {
      console.error('SSE连接错误:', error);
      this.isConnecting = false;
      this.stopHeartbeat();
      this.emit('error', error);
      
      // 尝试重连
      this.reconnect();
    };
    
    // 自定义事件
    this.eventSource.addEventListener('heartbeat', () => {
      this.resetHeartbeat();
    });
    
    this.eventSource.addEventListener('done', () => {
      this.emit('done');
      this.close();
    });
  }
  
  // 重连逻辑
  reconnect() {
    if (this.reconnectAttempts >= this.options.maxReconnectAttempts) {
      console.error('达到最大重连次数');
      this.emit('maxReconnectAttemptsReached');
      return;
    }
    
    this.reconnectAttempts++;
    console.log(`尝试重连 (${this.reconnectAttempts}/${this.options.maxReconnectAttempts})`);
    
    // 指数退避算法
    const delay = this.options.reconnectInterval * Math.pow(2, this.reconnectAttempts - 1);
    
    setTimeout(() => {
      this.connect();
    }, delay);
  }
  
  // 心跳检测
  startHeartbeat() {
    this.heartbeatTimer = setTimeout(() => {
      console.warn('心跳超时，可能断线');
      this.close();
      this.reconnect();
    }, this.options.heartbeatTimeout);
  }
  
  resetHeartbeat() {
    if (this.heartbeatTimer) {
      clearTimeout(this.heartbeatTimer);
    }
    this.startHeartbeat();
  }
  
  stopHeartbeat() {
    if (this.heartbeatTimer) {
      clearTimeout(this.heartbeatTimer);
    }
  }
  
  // 事件监听
  on(event, callback) {
    if (!this.listeners.has(event)) {
      this.listeners.set(event, []);
    }
    this.listeners.get(event).push(callback);
  }
  
  emit(event, data) {
    const callbacks = this.listeners.get(event) || [];
    callbacks.forEach(callback => callback(data));
  }

      this.eventSource.close();
      this.eventSource = null;

    this.emit('close');
  }
  
  // 发送消息（通过HTTP POST）
  async send(message) {
    const response = await fetch(this.url, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(message)
    });
    
    return response.json();
  }
}
```

## 8. Markdown分块渲染算法你们是怎么做的？

```javascript
class MarkdownChunkRenderer {
  constructor(options = {}) {
    this.options = {
      chunkSize: 1000, // 每个块的字符数
      overlap: 100, // 重叠字符数
      renderDelay: 50, // 渲染延迟
      ...options
    };
    
    this.chunks = [];
    this.renderedChunks = [];
    this.parser = new marked.Parser();
    this.renderer = new marked.Renderer();
  }
  
  // 分块算法
  splitIntoChunks(markdown) {
    const chunks = [];
    let position = 0;
    
    while (position < markdown.length) {
      // 智能分割点
      const splitPoint = this.findSplitPoint(markdown, position);
      
      const chunk = markdown.slice(position, splitPoint);
      chunks.push({
        id: chunks.length,
        content: chunk,
        startIndex: position,
        endIndex: splitPoint
      });
      
      // 重叠处理
      position = splitPoint - this.options.overlap;
      if (position >= markdown.length) break;
    }
    
    return chunks;
  }
  
  // 寻找智能分割点
  findSplitPoint(text, startPosition) {
    const targetEnd = startPosition + this.options.chunkSize;
    
    if (targetEnd >= text.length) {
      return text.length;
    }
    
    // 优先在段落边界分割
    const paragraphBreak = text.lastIndexOf('\n\n', targetEnd);
    if (paragraphBreak > startPosition + this.options.chunkSize * 0.5) {
      return paragraphBreak + 2;
    }
    
    // 其次在句子边界分割
    const sentenceBreak = text.lastIndexOf('.', targetEnd);
    if (sentenceBreak > startPosition + this.options.chunkSize * 0.5) {
      return sentenceBreak + 1;
    }
    
    // 最后在单词边界分割
    const wordBreak = text.lastIndexOf(' ', targetEnd);
    if (wordBreak > startPosition + this.options.chunkSize * 0.5) {
      return wordBreak + 1;
    }
    
    // 强制分割
    return targetEnd;
  }
  
  // 渲染单个块
  renderChunk(chunk) {
    try {
      const html = marked.parse(chunk.content, {
        renderer: this.renderer,
        breaks: true,
        gfm: true
      });
      
      return {
        id: chunk.id,
        html,
        metadata: {
          startIndex: chunk.startIndex,
          endIndex: chunk.endIndex,
          length: chunk.content.length
        }
      };
    } catch (error) {
      console.error('渲染块失败:', error);
      return {
        id: chunk.id,
        html: `<div class="error">渲染失败: ${error.message}</div>`,
        metadata: chunk
      };
    }
  }
  
  // 异步渲染所有块
  async renderAll(markdown, onChunkRendered) {
    this.chunks = this.splitIntoChunks(markdown);
    this.renderedChunks = [];
    
    for (const chunk of this.chunks) {
      const rendered = this.renderChunk(chunk);
      this.renderedChunks.push(rendered);
      
      if (onChunkRendered) {
        onChunkRendered(rendered);
      }
      
      // 延迟渲染，避免阻塞主线程
      await this.delay(this.options.renderDelay);
    }
    
    return this.renderedChunks;
  }
  
  // 合并渲染结果
  mergeChunks() {
    return this.renderedChunks
      .sort((a, b) => a.id - b.id)
      .map(chunk => chunk.html)
      .join('\n');
  }
  
  delay(ms) {
    return new Promise(resolve => setTimeout(resolve, ms));
  }
}
```

```javascript
class LargeMarkdownHandler {
  constructor() {
    this.virtualizer = null;
    this.worker = null;
    this.debounceTimer = null;
  }
  
  // 1. 防抖处理
  debounce(func, wait) {
    return (...args) => {
      clearTimeout(this.debounceTimer);
      this.debounceTimer = setTimeout(() => func.apply(this, args), wait);
    };
  }
  
  // 2. Web Worker解析
  async parseInWorker(markdown) {
    return new Promise((resolve, reject) => {
      this.worker = new Worker(new URL('./markdown-worker.js', import.meta.url));
      
      this.worker.postMessage({ action: 'parse', markdown });
      
      this.worker.onmessage = (event) => {
        if (event.data.action === 'parsed') {
          resolve(event.data.chunks);
        } else if (event.data.action === 'error') {
          reject(new Error(event.data.error));
        }
      };
      
      this.worker.onerror = (error) => {
        reject(error);
      };
    });
  }
  
  // 3. 虚拟滚动优化
  initVirtualizer(container, chunks) {
    this.virtualizer = new VirtualScroller({
      container,
      itemHeight: 50, // 估计高度
      totalItems: chunks.length,
      renderItem: (index) => {
        const chunk = chunks[index];
        return this.renderChunk(chunk);
      },
      overscan: 5 // 预渲染数量
    });
  }
  
  // 4. 渐进式渲染
  async progressiveRender(chunks, container) {
    const batchSize = 10;
    let currentIndex = 0;
    
    const renderBatch = () => {
      const batch = chunks.slice(currentIndex, currentIndex + batchSize);
      
      batch.forEach(chunk => {
        const element = this.createChunkElement(chunk);
        container.appendChild(element);
      });
      
      currentIndex += batchSize;
      
      if (currentIndex < chunks.length) {
        // 使用requestIdleCallback在空闲时渲染
        requestIdleCallback(renderBatch, { timeout: 100 });
      }
    };
    
    requestIdleCallback(renderBatch, { timeout: 100 });
  }
  
  // 5. 滚动优化
  optimizeScrolling(container) {
    let ticking = false;
    
    const onScroll = this.debounce(() => {
      if (!ticking) {
        requestAnimationFrame(() => {
          // 只渲染可视区域
          this.renderVisibleChunks(container);
          ticking = false;
        });
        ticking = true;
      }
    }, 16); // 60fps
    
    container.addEventListener('scroll', onScroll, { passive: true });
    
    return () => {
      container.removeEventListener('scroll', onScroll);
    };
  }
  
  // 6. 内存管理
  cleanupOffscreenChunks(container) {
    const viewportHeight = container.clientHeight;
    const scrollTop = container.scrollTop;
    
    // 移除屏幕外的块
    container.querySelectorAll('.chunk').forEach(chunk => {
      const rect = chunk.getBoundingClientRect();
      const containerRect = container.getBoundingClientRect();
      
      // 判断是否在可视区域外
      if (rect.bottom < containerRect.top - 1000 || 
          rect.top > containerRect.bottom + 1000) {
        chunk.remove();
      }
    });
  }
}

         }, 30000);
```
   ```javascript
       });
     }
   ```
