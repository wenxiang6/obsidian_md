# 字节跳动 AI前端工程师 面试题（第1组）

## 1. React 的渲染机制中，如何优化AI聊天机器人这种频繁更新state的场景？

**答案：**
- **使用React.memo**：对纯展示组件进行记忆化，避免不必要的重渲染
- **使用useMemo和useCallback**：缓存计算结果和回调函数
- **虚拟滚动**：对于长列表聊天记录，使用react-window或react-virtualized
- **状态拆分**：将频繁更新的状态（如输入内容）与低频更新状态（如历史消息）分离
- **防抖节流**：对输入事件进行防抖，对滚动事件进行节流
- **Web Workers**：将繁重的数据处理移到Web Worker中
- **批量更新**：使用unstable_batchedUpdates或React 18的自动批处理

## 2. 详细说明一下如何实现AI自动滚动到底部，并处理用户手动向上滚动时的冲突？

**答案：**
```javascript
const ChatContainer = () => {
  const containerRef = useRef(null);
  const [autoScroll, setAutoScroll] = useState(true);
  
  // 监听滚动事件
  const handleScroll = () => {
    const { scrollTop, scrollHeight, clientHeight } = containerRef.current;
    // 判断是否接近底部（阈值100px）
    const isNearBottom = scrollHeight - scrollTop - clientHeight < 100;
    setAutoScroll(isNearBottom);
  };
  
  // 新消息到来时
  useEffect(() => {
    if (autoScroll && containerRef.current) {
      containerRef.current.scrollTop = containerRef.current.scrollHeight;
    }
  }, [messages, autoScroll]);
  
  return (
    <div 
      ref={containerRef} 
      onScroll={handleScroll}
      style={{ overflow: 'auto', height: '400px' }}
    >
      {messages.map(msg => <Message key={msg.id} {...msg} />)}
    </div>
  );
};
```

**关键点：**
- 使用阈值判断用户是否在底部附近
- 用户手动滚动时暂停自动滚动
- 新消息到来且autoScroll为true时才滚动到底部

## 6. 请解释一下Token的概念，以及前端如何估算Prompt的Token长度？

**答案：**
**Token概念：**
- Token是文本处理的基本单位
- 英文：1个单词约1-2个token
- 中文：1个汉字约1-2个token
- 代码：变量名、关键字等都是token

**前端估算方法：**

1. **简单估算**：
   ```javascript
   function estimateTokens(text) {
     // 英文：按空格分词
     const englishWords = text.match(/[a-zA-Z]+/g) || [];
     // 中文：按字符计数
     const chineseChars = text.match(/[\u4e00-\u9fa5]/g) || [];
     // 标点符号
     const punctuation = text.match(/[^\w\s\u4e00-\u9fa5]/g) || [];
     
     return englishWords.length * 1.3 + chineseChars.length * 1.5 + punctuation.length;
   }
   ```

2. **使用tiktoken库**（更准确）：
   ```javascript
   import { Tiktoken } from 'tiktoken';
   
   const enc = new Tiktoken({ model: 'gpt-3.5-turbo' });
   const tokens = enc.encode('你好世界');
   console.log(tokens.length); // 实际token数
   ```

3. **前端展示**：
   - 实时显示当前token数
   - 接近限制时警告
   - 历史消息token统计

## 8. 手写题：实现一个简单的流式数据解析器，将Uint8Array转换为文本块

**答案：**
```javascript
class StreamParser {
  constructor() {
    this.decoder = new TextDecoder();
    this.buffer = '';
    this.chunks = [];
  }
  
  // 处理Uint8Array数据
  parseChunk(uint8Array) {
    const text = this.decoder.decode(uint8Array, { stream: true });
    this.buffer += text;
    
    // 按换行符分割
    const lines = this.buffer.split('\n');
    
    // 最后一行可能不完整，保留到下次处理
    this.buffer = lines.pop() || '';
    
    // 处理完整的行
    for (const line of lines) {
      if (line.trim()) {
        this.chunks.push(line);
        this.onChunk(line);
      }
    }
  }
  
  // 完成解析
  finish() {
    if (this.buffer.trim()) {
      this.chunks.push(this.buffer);
      this.onChunk(this.buffer);
    }
    this.buffer = '';
    return this.chunks;
  }
  
  // 回调函数，子类可重写
  onChunk(chunk) {
    console.log('收到文本块:', chunk);
  }
}

// 使用示例
const parser = new StreamParser();
parser.onChunk = (chunk) => {
  // 处理每个文本块
  displayChunk(chunk);
};

// 模拟流式数据
async function* generateStream() {
  const encoder = new TextEncoder();
  yield encoder.encode('Hello, ');
  yield encoder.encode('World!\n');
  yield encoder.encode('This is ');
  yield encoder.encode('streaming data.');
}

// 处理流
async function processStream() {
  for await (const chunk of generateStream()) {
    parser.parseChunk(chunk);
  }
  parser.finish();
}
```
