一句话读懂音巢

音巢不是又一个聊天机器人框架，它把 Agent 定义为「数字员工」：持久身份（soul.md）、长期记忆（memory.md）、私有工作区、自主意识（Focus + 触发器）、可被组织管（RBAC/OKR/审批/配额）、可被观测（运行事件流）。

LLM 推理走外部 API，平台负责把「人 + Agent + 组织」装进同一套工程底座：FastAPI 单体 + LangGraph 持久化运行时 + 数据库表做工作队列。

从「能跑的 Demo」到「能运营的组织」

单 Agent 对话谁都会写，难的是把身份、记忆、自主意识、协作、权限、观测全部做成工程闭环。

音巢的价值恰在于此：它不是演示能力的合集，而是一套让数字员工「入职、干活、被管、被看见」的完整操作系统。

建议从 00 开始，按顺序读完 12 篇——你会得到一套完整的 Agent 平台设计决策库。
